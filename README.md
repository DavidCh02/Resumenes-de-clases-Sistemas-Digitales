# 🚀 Sistemas Digitales — Apuntes y Prácticas (ESP32 / AVR)

Repositorio oficial que recopila los apuntes digitalizados, análisis teóricos, configuraciones de registros a bajo nivel y prácticas de laboratorio desarrolladas durante el curso de **Sistemas Digitales** de la Carrera de Computación de la **Universidad Nacional de Loja (UNL)**.

---

## 📚 Contenido del Repositorio

El contenido está estructurado de manera modular y progresiva, migrando desde arquitecturas tradicionales de 8 bits hacia microcontroladores avanzados de 32 bits y sistemas operativos de tiempo real:

| Módulo / Clase | Tema Principal | Archivo de Apuntes |
| :--- | :--- | :--- |
| **Clase 1 a 5** | Fundamentos de microcontroladores, lógica combinacional y mapeo de memoria en AVR | [Ver Documentación](./) |
| **Clase 6** | Arquitectura comparativa: Atmega328P vs. ESP32-WROOM-32 | [Ver Documentación](./) |
| **Clase 7** | Conectividad avanzada, Matriz GPIO / IO-MUX y registros atómicos (`W1TS`/`W1TC`) | [`Clase_7_Sistemas_Digitales.docx`](./Clase_7_Sistemas_Digitales.docx) |
| **Clase 8** | Temporizadores de hardware (*Timers*), buses APB, prescaler y cálculo de resolución | [`Clase_8_Sistemas_Digitales.docx`](./Clase_8_Sistemas_Digitales.docx) |
| **Clase 9** | Interrupciones externas: Sondeo (*Polling*) vs. Interrupciones y modos de flanco (`FALLING`, `RISING`, `CHANGE`) | [`Clase_9_Sistemas_Digitales.docx`](./Clase_9_Sistemas_Digitales.docx) |
| **Clase 10** | Anatomía de una ISR, optimización en IRAM (`IRAM_ATTR`), sincronización con `volatile`, Patrón Bandera y Antirrebote | [`Clase_10_Sistemas_Digitales.docx`](./Clase_10_Sistemas_Digitales.docx) |

* **Hardware:** Microcontrolador ESP32 (ESP-WROOM-32), módulo DevKit V1, ATmega328P.
* **Entornos y Simulación:** Arduino IDE, Plataforma Wokwi[cite: 44].
* **Lenguajes:** C / C++ para sistemas embebidos.
* **Procesamiento y Gestión:** Control de versiones mediante Git & GitHub.
